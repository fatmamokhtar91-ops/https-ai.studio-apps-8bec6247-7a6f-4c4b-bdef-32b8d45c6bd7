# فاطمة عمر | فيديوهات إعلانية بالذكاء الاصطناعي

مشروع شخصي منفصل عن قالب Payhip.

## تشغيل المعاينة
1. `npm install`
2. `npm run dev`
3. افتح عنوان Vite المحلي الظاهر في الطرفية.

## البناء
`npm run build` ثم `npm run preview`.

## محتويات
- `index.html`: الصفحة والتصميم RTL والأسعار/الحاسبة/النموذج/التواصل.
- `public/videos/`: ستة فيديوهات مستخرجة من HTML المرفوع، دون استبدالها بأعمال وهمية.
- `package.json`, `vite.config.js`: إعدادات Vite.

## ملاحظات
الموقع لم يُنشر. راجعي روابط التواصل، حساب الدفع، تشغيل الفيديوهات وتجربة إرسال نموذج واتساب قبل النشر.
